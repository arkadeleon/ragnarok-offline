# คัดลอกไฟล์ไคลเอนต์ Ragnarok Online ไปยังอุปกรณ์ของคุณ

## วิธีที่ 1: Wi-Fi (จาก Windows ไปยัง iPhone/iPad)

**ขั้นตอนที่ 1 — แชร์โฟลเดอร์บน Windows**

1. คลิกขวาที่โฟลเดอร์ไคลเอนต์ kRO แล้วเลือก **คุณสมบัติ**
2. เปิดแท็บ **การแชร์** แล้วคลิก **การแชร์ขั้นสูง**
3. ทำเครื่องหมายที่ **แชร์โฟลเดอร์นี้** แล้วคลิก **OK**
4. เปิด **การตั้งค่า** → **เครือข่ายและอินเทอร์เน็ต** และตรวจสอบว่าโปรไฟล์เครือข่ายตั้งไว้เป็น **ส่วนตัว**
5. ใน **แผงควบคุม** → **ศูนย์เครือข่ายและการแชร์** → **เปลี่ยนการตั้งค่าการแชร์ขั้นสูง** เปิดใช้งาน **การค้นพบเครือข่าย** และ **การแชร์ไฟล์และเครื่องพิมพ์**

**ขั้นตอนที่ 2 — ค้นหาที่อยู่ IP ของ PC**

กด **Win + R** พิมพ์ `cmd` กด Enter แล้วพิมพ์ `ipconfig` จดบันทึก **ที่อยู่ IPv4** (เช่น `192.168.1.10`)

**ขั้นตอนที่ 3 — เชื่อมต่อจาก iOS**

1. เปิดแอป **ไฟล์**
2. แตะ **···** ที่มุมขวาบน แล้วเลือก **เชื่อมต่อกับเซิร์ฟเวอร์**
3. ป้อน `smb://192.168.1.10` (ใช้ IP ของ PC ของคุณ)
4. ป้อนชื่อผู้ใช้และรหัสผ่าน Windows แล้วแตะ **เชื่อมต่อ**

**ขั้นตอนที่ 4 — คัดลอกไฟล์**

คัดลอกรายการต่อไปนี้ไปยังโฟลเดอร์ **Ragnarok Offline** ในส่วน **บน iPhone/iPad ของฉัน** (กดค้างที่แต่ละรายการแล้วแตะ **คัดลอก** จากนั้นไปยังตำแหน่งปลายทางแล้วแตะ **วาง**):

- **data.grf**
- โฟลเดอร์ **BGM**

## วิธีที่ 2: สาย USB

**Mac:** เชื่อมต่ออุปกรณ์ → เปิด **Finder** → เลือก iPhone/iPad → แท็บ **ไฟล์** → ขยาย **Ragnarok Offline** → ลากไฟล์เข้าไป

**Windows:** เชื่อมต่ออุปกรณ์ → เปิด **iTunes** → เลือกอุปกรณ์ → **การแชร์ไฟล์** → เลือก **Ragnarok Offline** → ลากไฟล์เข้าไป
